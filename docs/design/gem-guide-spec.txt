WHAT THIS IS
A single amethyst gem is the guide. It lives on the left rail and states the one
most-valuable next move in plain language. No quest chrome: no markers, no labels,
no Track button, no turn-in. Three poses (resting / offering / celebrating) carry
all the affect. Plum stays the system accent; the gem is the one vivid focal point.

GEOMETRY (viewBox "-8 -8 136 136" for every placement; overflow visible so bloom
+ contact shadow extend past the box)
  Outer octagon: 8 vertices on a circle centered (60,58) r=46, first vertex at
    -90° (top), step 45°:
      (60,12) (92.5,25.46) (106,58) (92.54,90.5) (60,104) (27.46,90.5) (14,58) (27.46,25.5)
  Inner (core) octagon: center (61,53) r=19, same angles:
      (61,34) (74.43,39.57) (80,53) (74.43,66.43) (61,72) (47.57,66.43) (42,53) (47.57,39.57)
  Ring facet i = polygon[outer_i, outer_(i+1), inner_(i+1), inner_i]  (8 facets)
  Core facet = the inner octagon.
  Contact shadow: <ellipse cx=60 cy=110 rx=30 ry=5.5 fill=url(#SH)>.
  Core hotspot: <circle cx=61 cy=50 r=20 fill=url(#CORE)>, opacity = per-pose.
  Bloom: <circle cx=60 cy=56 r=56 fill=url(#BLOOM)> wrapped in
         translate(60 58) scale(BLOOM) translate(-60 -58), BLOOM = per-pose.

GEM MATERIAL (exact gradients)
  Ring facet fills — linearGradient x1 0 y1 0 x2 0.3 y2 1, stop0 -> stop1
   (light upper-left → deep lower-right):
    R0 #D9C2F4 → #B492EA      R1 #C2A0EC → #9B72DE
    R2 #9E78DC → #6D3DBE      R3 #7E54C8 → #5226A0
    R4 #8A5ECF → #5A2BA8      R5 #A885E2 → #7344C4
    R6 #C6A6EE → #9068D8      R7 #E6D6FA → #C2A0EC
  Core facet (C): linearGradient (same axis) #F6EFFF → #CBADF0
  Core hotspot (CORE): radialGradient cx50% cy46% r55%
    0% #FFFFFF @.95 · 34% #F0E4FF @.55 · 100% #D9C2F4 @0
  Bloom (BLOOM): radialGradient cx50% cy48% r50%
    0% #B98CF0 @.6 · 40% #8A5ED2 @.26 · 72% #7C50CE @0
  Contact shadow (SH): radialGradient cx50% cy50% r50%
    0% #34176A @.3 · 70% #34176A @0
  Seams: stroke #EBDDFB width 1.25 opacity 0.8 (linejoin/linecap round) — the
    inner octagon outline + 8 spoke lines outer_i→inner_i.
  Rim: outer octagon stroke #F3EBFF width 1.7 opacity 0.9.
  Sparkle: 4-point star, fill #FFFFFF. Star(x,y,R,rat,op): vertical radius R,
    horizontal radius R*rat, waist offset w=R*0.13 → points
    (x,y-R)(x+w,y-w)(x+R*rat,y)(x+w,y+w)(x,y+R)(x-w,y+w)(x-R*rat,y)(x-w,y-w).

PER-POSE DIFFERENCES (the only things that change)
  RESTING   bloom scale 1.00 · hotspot opacity 0.82 · sparkles: 1
              star(61,49, R12, rat .62, op .85)            [small core glint]
  OFFERING  bloom scale 1.14 · hotspot opacity 0.95 · sparkles: 3
              star(61,49, R24, .66, .97)                    [bright core burst]
              star(93,30, R8, .70, .92) · star(101,42, R3.6, .80, .80)
  CELEBRATE bloom scale 1.34 · hotspot opacity 1.00 · sparkles: 5
              star(61,49, R28, .70, 1.0)
              star(94,27, R9, .70, .95) · star(26,33, R6.5, .70, .90)
              star(103,46, R4, .80, .82) · star(20,52, R3.4, .80, .70)
  Reading: brightness (hotspot opacity) + glow size (bloom scale) + sparkle count
  all step up rest → offer → celebrate. Nothing else (geometry/fills) changes.

================================================================================
7. VOICE — WHAT THE GEM SAYS, BY STAGE
================================================================================
Terse coach. One move per stage. {Company}/{N} are interpolated.
  Applied        "Get a first read on {Company}."                                  → Quick Prep
  Screen         "Prep your {Company} screen. Screens reward clear thinking out loud." → Deep Prep
  Hiring Manager "Read the room before the {Company} HM call."                       → Deep Prep
  Full Loop      "Prep all {N} rounds at {Company}."                                 → Deep Prep
  Offer          "See how {Company} stacks up, then walk in ready to negotiate."     → Compare & negotiate
Priority when several apply: prep-due interview > quick-prep gap > apply pace.
The gem says exactly one thing at a time; when nothing is urgent it rests.
