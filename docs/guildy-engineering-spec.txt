--------------------------------------------------------------------------------
3c. STATE / JS (the only behavior)
--------------------------------------------------------------------------------
State:
  sheetOpen  : bool   compensation sheet visible (gated by compActive)
  prepOpen   : bool   job-prep overlay visible
  whereOpen  : bool   "Where to look" expanded
  bannerOpen : bool   prep toast visible
  compState  : 'active' | 'locked'   (prop) — active shows the gradient comp bar,
               locked shows the muted lock bar; sheet only opens when active.

Handlers:
  openSheet()     -> if compActive: sheetOpen = true        (comp bar, Compare offers,
                                                              Negotiation Prep hooks)
  closeSheet()    -> sheetOpen = false                       (scrim, X)
  openPrep()      -> prepOpen = true; bannerOpen = true;
                     setTimeout(()=> bannerOpen=false, 6000)  (Screen/HM job cards)
  closePrep()     -> clearTimeout; prepOpen = false           (prep X)
  dismissBanner() -> clearTimeout; bannerOpen = false         (toast X)
  toggleWhere()   -> whereOpen = !whereOpen                   (Where-to-look trigger)

Derived:
  compActive = compState === 'active'
  compLocked = !compActive
  sheetOpen  = sheetOpen && compActive

That is the entire interaction model. Everything else is static presentation.
